## 段階1　骨組み・設定データの形・見本の2店・空きの計算・テスト（2026-10-29）

### やったこと

```
shop/
  CLAUDE.md            … 作業指示書2
  index.html           … 入口（段階1では見本の2店を並べるだけ）
  css/style.css        … レッスン予約の css を写したもの。色は5色から選べる（body の data-color）
  js/shops.js          … お店の設定の形・見本の2店・見本の予約（数字や文はここ）
  js/availability.js   … 空きの計算（ここだけ）。「席×人数」「担当×メニュー」に広げた

  tests/               … ブラウザで開くテストページ（20件）
  screenshots/         … 段階ごとの写真
```

- **設定データの形**（`js/shops.js` の先頭に説明を書いた）：お店1つを1つのオブジェクトにまとめた。段階3で、この形のままファイルに書き出し・読み込みする
  - 営業時間は曜日ごとに「部」を並べる（`weeklyHours[曜日] = [{ start, end }, …]`、1日2部まで）。部の名前（昼・夜）は `partNames`
  - メニューの「昼のみ」「夜のみ」は、受ける部の番号で持つ（`parts: [0]` なら第1部だけ、`[]` ならどの部も）
  - 飲食店は `seats`（名前・種類・定員）、サロンは `staff`（名前・休みの曜日）
  - お客さんに聞くことは3択（`askFor`、既定は「名前＋電話」）。キャンセル料は `cancel.feeEnabled` と `cancel.feeDetail`
- **空きの計算**：入口は `ShopAvailability.getAvailability(お店, 条件, 今の日時)` と `isStillAvailable(お店, 枠, 今の日時, 予約)`
  - 飲食店：人数が定員以下で、種類の希望（「どれでもよい」が既定）に合う席を、**小さい席から順に**探して、空いている最初の席を割り当てる
  - サロン：指名ならその担当、「指名なし」なら並び順に、その曜日がお休みでない担当を探して、空いている最初の担当を割り当てる
  - 予約は「始まり〜終わり＋片付けの時間」のあいだ、その席・担当を使う。新しい予約にも片付けの時間をつけて重なりを見る
  - 締め切りは「始まりの◯時間前まで」。ちょうど◯時間前は受け付ける
  - 受けない時間は、お店全体にかかる（席ごと・担当ごとではない）
- **見本の2店**：指示書の営業時間・席・担当・メニュー・片付けの時間をそのまま入れた。見本の予約は各店7件、受けない時間は各店1件（ゆずり葉：貸し切りのため 夜／こもれび：講習のため 午前）。日付は「今日から数えて何番目の営業日か」で書き、初めて開いたときに本当の日付に置きかえる
- 保存の名前を `ee-shop-demo` にして、レッスン予約（`ee-yoyaku-demo`）の保存データとまざらないようにした
- **直下（レッスン予約）の `js/` には手をつけていない。** 必要な部品は `shop/js/` に写して名前を変えた（`Availability` → `ShopAvailability` など。同じページで読みこんでもぶつからないように）

### 確かめたこと

- お店のテスト **20件すべて成功**（幅390・768・1440px）。指示書の8項目はすべて入れた
- 直下のレッスン予約のテスト **28件も成功**。レッスン予約のトップも、いつもどおり開く
- テストが本当に間違いを見つけるかを確かめるため、わざと計算を5か所こわして動かした（片付けの時間を無視／人数を無視／担当の休みを無視／締め切りを無視／昼のみ・夜のみを無視）。どれもテストが失敗になり、元に戻すと全部通った
- console のエラー 0件、横にはみ出す画面なし

### うまくいかなかったこと・やり直したこと

- 「同じ席に片付けの時間を含めて重ならない」のテストで、最初は 13:15 開始の昼のおまかせ（60分）が空くことを確かめようとした。昼の部は 14:00 までなので 13:15 開始は営業時間からはみ出し、そもそも枠がなかった。テストの中だけ昼の部を 15:00 までにのばして確かめた（見本のお店の営業時間は指示書のまま）
- 営業時間のない曜日の理由が「満席」になってしまう作りだった（理由を「その日の枠の理由」から決めていたが、枠が0個だったため）。テストを書く前に気づき、枠が0個の日は「定休日」と出すようにした
- 見本の予約で、こもれびの「森さんを指名」の1件は、日付が開いた日しだいで木曜（森さんのお休み）に当たることがある。そのときは指名なしで入れなおすようにした
- 作業枝の作り直しで force push が止められた（上の「始める前に」）

### たけさんへの質問（返事を待っています）

1. **見本の2店の「予約のきまり」**は指示書にないので、仮に決めました。ゆずり葉：締め切り3時間前・30日先まで・30分刻み。こもれび：締め切り1時間前・30日先まで・30分刻み。よいですか
2. **一言紹介・住所・キャンセルの文**も仮です。住所は「兵庫県豊岡市（見本のため架空の住所です）」。ゆずり葉はキャンセル料あり（「当日のキャンセルは、コース料金の50%をいただきます」）、こもれびはなし、にしました
3. **コースの金額は1名あたり**として表示するつもりです。人数をかけた合計も出しますか
4. **カウンター（1名席）を2席つなげて2名で使う**ことはしていません（指示書の「人数が席の定員を超える席は選ばない」のとおり）。2名のお客さんにカウンターを出したい場合は教えてください
5. **コースはその部の終わりまでに食べ終わる**時間だけを出しています（夜のおまかせ120分なら最後は19:00）。片付けの時間は閉店後にはみ出してもよい、としました
6. **受けない時間はお店全体**にかけています。「この席だけ」「この担当だけ」受けない、が必要なら教えてください
7. **祝日はお休みにしていません**（指示書は定休日・臨時休業だけ）。祝日も営業する前提でよいですか
8. **「指名なし」の割り当て**は、担当の並び順に空いている人を選びます。予約の少ない人から割り当てる、などの決め方がよければ教えてください
9. 消費税は、飲食も店内で食べる前提で **10%** にしました
